# Wiki maintenance

Markdown pages in this folder are the versioned source of the internal-edition GitHub wiki. Publish only to digitalrcs/grafana-intelligence-gateway-private.wiki.git. When publishing, omit this maintenance file and remove .md suffixes from local wiki-page links. Keep image files alongside the pages. The repository and wiki are publicly readable; private refers to Grafana distribution and signing, not source visibility. Never add credentials, customer data or target-specific deployment configuration.
